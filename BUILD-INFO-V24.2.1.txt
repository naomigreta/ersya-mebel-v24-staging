- Pemeriksaan build kini menguji keberadaan schema FurnitureStore, field kontak/lokasi utama, dan ketiadaan aggregateRating self-serving.

Verifikasi lokal: jalankan `npm run build`. Hasil build lokal tidak membuktikan deploy/indeks Google.

Catatan: database produksi ERSYA telah menerima migrasi aman untuk products.image_alt. Sebelum deploy kode V24.2.1, pastikan Netlify environment variable ERSYA_GEMINI_API_KEY sudah dipasang oleh pemilik akun. Lakukan Deploy Preview dan pengujian end-to-end satu foto/satu jadwal sebelum produksi.
