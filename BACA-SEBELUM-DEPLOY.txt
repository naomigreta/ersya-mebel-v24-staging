ERSYA MEBEL V24.2.3 — CATATAN PRA-DEPLOY

Paket ini adalah source project untuk Netlify, bukan arsip HTML statis. Konfigurasi netlify.toml mengatur:
- Build command: npm run build
- Publish directory: public
- Functions directory: netlify/functions
- Node.js: 22

Gunakan deploy manual pada situs Netlify ERSYA yang sudah ada. Login terlebih dahulu, buka situs tersebut, lalu gunakan area manual deploy di tab Deploys. Netlify Drop menerima ZIP/folder; bila antarmuka meminta folder, ekstrak ZIP dan unggah folder proyek. Pastikan Netlify menjalankan build dan menyertakan Functions. Jangan unggah folder public saja karena endpoint server akan hilang.

Jangan membuat situs baru jika ingin mempertahankan URL lama. Jangan menghapus database, mengganti akun Supabase/Cloudinary, atau menjalankan SQL instalasi massal.

Environment variable wajib untuk analisis visual:
ERSYA_GEMINI_API_KEY = API key Gemini milik pemilik situs, disimpan sebagai secret di Netlify.

Auto Pilot produksi tetap nonaktif sampai login Admin, analisis foto Gemini nyata, upload Cloudinary, penyimpanan Supabase, dan alur Cron -> publish -> halaman produk -> sitemap diuji end-to-end.
