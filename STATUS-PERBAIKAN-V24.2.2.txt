Perubahan dari paket V24.2.1:

Pengujian: npm run build lulus, termasuk semua smoke test functions, Gemini image analysis, deploy context, Auto Pilot schedule, Supabase-lite, admin render security, dan Base64 storage regression.

PENTING: Paket ini belum dideploy ke Netlify. Tes lokal bukan bukti integrasi online atau peringkat Google. Sebelum produksi, pasang ERSYA_GEMINI_API_KEY sebagai secret di Netlify, lakukan Deploy Preview, dan uji browser Android, analisis foto nyata, upload Cloudinary, serta jadwal publikasi end-to-end. Auto Pilot produksi harus tetap nonaktif sampai pengujian itu lulus.
