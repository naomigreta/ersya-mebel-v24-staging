ERSYA MEBEL V24.2.3 — PAKET DEPLOY NETLIFY LANGSUNG

PAKET INI MELANJUTKAN WEBSITE ERSYA MEBEL YANG SUDAH ADA.
JANGAN membuat situs Netlify baru jika tujuanmu memperbarui alamat website Ersya Mebel yang sekarang.

CARA DEPLOY TANPA GITHUB
1. Simpan ZIP ini sebagai cadangan versi V24.2.3.
2. Login ke akun Netlify yang memiliki situs Ersya Mebel.
3. Buka situs Ersya Mebel yang alamatnya sekarang sudah dipakai.
4. Buka tab Deploys, cari area manual deploy / drag and drop.
5. Unggah ZIP ini. Jika Netlify meminta folder, ekstrak ZIP lalu unggah folder proyek hasil ekstrak (folder yang berisi package.json, netlify.toml, public, dan netlify).
6. Pastikan Netlify menjalankan build `npm run build`, publish directory `public`, dan Functions directory `netlify/functions` sesuai netlify.toml.
7. Jangan menganggap deploy berhasil hanya karena file selesai diunggah. Tunggu status Published/Published to production dan periksa tab Functions.

PENTING UNTUK FITUR SERVER
Website ini bukan hanya HTML statis. Gemini Vision, halaman produk server-rendered, dan sitemap dinamis memakai Netlify Functions. Deploy manual harus menjalankan build dan menyertakan Functions. Jika Netlify hanya menerbitkan isi folder public tanpa Functions, fitur tersebut tidak akan berfungsi. Jangan lanjutkan pengujian Auto Pilot sampai Functions muncul dan berjalan.

KONFIGURASI RAHASIA NETLIFY
Tambahkan Environment Variable di situs Netlify:
- Name: ERSYA_GEMINI_API_KEY
- Value: API key milikmu dari https://aistudio.google.com/app/apikey
Simpan sebagai secret server-side. Jangan menaruh API key di ZIP, HTML, JavaScript publik, GitHub, atau chat. Setelah menambahkan/mengubah secret, jalankan deploy ulang.
Model bawaan: gemini-3.5-flash-lite. Kuota gratis dapat berubah dan tidak tanpa batas.

KONEKSI DATA YANG SUDAH ADA
Paket ini memakai konfigurasi Supabase/Cloudinary ERSYA yang sudah ada. Jangan membuat database baru, jangan menjalankan ulang skrip database massal, dan jangan mengganti kredensial lama tanpa alasan. Migrasi kolom products.image_alt sudah diterapkan dan diverifikasi pada database aktif tanggal 3 November 2026.

UJI SETELAH DEPLOY
1. Buka homepage dan pastikan alamat domain tetap sama.
2. Buka /admin.html dan login dengan akun Admin lama.
3. Uji satu foto: analisis Gemini, periksa/edit hasil, lalu simpan.
4. Pastikan foto tersimpan ke Cloudinary dan metadata tersimpan ke Supabase.
5. Uji satu jadwal beberapa menit ke depan. Pastikan Cron memublikasikan produk, halaman /produk/<slug>/ muncul, dan /sitemap.xml memuat produk itu.
6. Jangan aktifkan batch besar atau Auto Pilot produksi sebelum seluruh alur satu foto dan satu jadwal lulus.

STATUS TES SEBELUM DEPLOY
- ZIP asli dapat dibuka tanpa error.
- `npm run build` lulus di lingkungan lokal, termasuk pemeriksaan struktur, Functions, Gemini (mock), jadwal Auto Pilot (simulasi), Supabase-lite, keamanan admin, dan regresi Base64.
- Ini bukan bukti bahwa deploy Netlify, panggilan Gemini nyata, upload Android, Cloudinary, atau publikasi Cron end-to-end sudah berhasil. Semua itu harus diuji setelah deploy.

PEMBARUAN SELANJUTNYA
Untuk pembaruan tanpa GitHub, unggah paket ZIP versi terbaru ke situs Netlify ERSYA yang sama melalui Deploys. Netlify akan membuat deploy baru pada situs yang sama; alamat website tidak perlu berubah. Simpan ZIP versi sebelumnya sebagai cadangan.
